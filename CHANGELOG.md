# Changelog

All notable changes to Fog of Walk are documented here.

## [0.8.0] - 2026-09-15

### Changed

- anomalies remover (#38)

## [0.7.0] - 2026-09-14

### Changed

- refactor fog and activities processing (major performance improvements, #37)
- activities bulk settings (#36)
- update help page with up-to-date info
- stop resetting fog mode while clearing map
- limit weekly chart to 180 days on profile page
- open account popup after the drawer is fully closed

### Changed

- improve wording on landing page
- add recording guide to landing page
- set map as homepage for installed PWA
- achievements rarity (#35)

## [0.5.0] - 2026-09-02

### Changed

- replace Drawer with Dialog in saved point edit dialog
- add sorting to my activities page (#33)

## [0.4.0] - 2026-08-31

### Changed

- add landing page (#32)

## [0.3.0] - 2026-08-31

- minor saved points improvements (#30)

## [0.2.1] - 2026-08-30

### Changed

- fix mobile issues in saved point edit dialog (part of them)

## [0.2.0] - 2026-08-30

## [0.1.1] - 2026-08-29

## [0.1.0] - 2026-08-29

### Changed

- GPX and FIT activity imports, including FIT laps and activity types
- fog clearing in corridor and filled-loop modes, with persistent map state
- photo matching, activity and lifetime statistics, share cards, and an installable PWA
- optional account-based activity sync, public profiles, achievements, and administration tools
- more reliable fog processing and a responsive map drawer experience.
