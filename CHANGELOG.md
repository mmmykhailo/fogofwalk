# Changelog

All notable changes to Fog of Walk are documented here.

## [0.5.0] - 2026-09-02

### Changed

- replace Drawer with Dialog in saved point edit dialog
- add sorting to my activities page (#33)

## [0.4.0] - 2026-08-31

### Changed

- add landing page (#32)

## [0.3.0] - 2026-08-31

### Changed

- refactor map view, fix several issues related to map & fog processing (#31)
- minor saved points improvements (#30)

## [0.2.1] - 2026-08-30

### Changed

- add uuid fallback
- improve release generation logic
- fix mobile issues in saved point edit dialog (part of them)

## [0.2.0] - 2026-08-30

### Changed

- add saved points (#29)

## [0.1.2] - 2026-08-29

### Changed

- add more metadata
- get rid of arctic oauth client

## [0.1.1] - 2026-08-29

### Changed

- document release process & improve deploy workflows

## [0.1.0] - 2026-08-29

### Changed

- GPX and FIT activity imports, including FIT laps and activity types
- fog clearing in corridor and filled-loop modes, with persistent map state
- photo matching, activity and lifetime statistics, share cards, and an installable PWA
- optional account-based activity sync, public profiles, achievements, and administration tools
- more reliable fog processing and a responsive map drawer experience.
